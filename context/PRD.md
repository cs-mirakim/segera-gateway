# PRD SEGERA

## Problem
Sistem analitik antarabangsa (seperti Walk Score US) tidak memahami konteks geografi Malaysia: tidak mengenali surau kariah, tidak mengesan stesen minyak bersurau, tidak mengesan risiko limpahan banjir kilat, tidak mengambil kira mod mobiliti motosikal tempatan, dan tidak menyokong penapis status halal.

## Competitors (Legit & Active 2026)
All active:
- walkscore.com (Redfin)
- traveltime.com (TravelTime platform)
- maps.openrouteservice.org (Heidelberg Uni)
- esri.com ArcGIS Urban
- app.15mincity.com (Carlos Moreno 15min city)
- Google Maps Nearby

## User Flow
Landing -> Pilih/Cari Lokasi Mana-Mana di Malaysia -> Lihat Fasiliti Dalam 5/10/15 Minit (Surau, Kedai, Klinik, Transit, Amaran Banjir) -> Semak Poligon Isochrone (Motosikal vs Jalan Kaki).
