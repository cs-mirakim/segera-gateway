# DESIGN.md - SEGERA Visual Direction

Purpose: Anti-slop filter needs direction. Without this, result is sterile draft.

Brand: SEGERA - cepat, tempatan, utility. Bukan startup purple gradient.

Mood: JPJ + DBKL + JAKIM dashboard. Paper texture off-white #FFFBF5, ink charcoal #1A1A1A.
Accent: Flood Blue #0E4D64 (banjir), Halal Green #1B7A3D, Surau Gold #C5A100, Warning Red #A11D33 for flood.

Typography:
- Headline: Instrument Serif 700, tight tracking
- Data: JetBrains Mono 400 for numbers, scores
- Body: Geist Sans 400

Anti-patterns to BAN:
- No bento grid 3x2
- No purple to blue gradient hero
- No "Unlock the power / Elevate your"
- No glowing dot beside heading
- No Lucide icons all same stroke
- No fake stats "10k+ users"

Liveliness: Use real KL data, e.g. "Saujana Utama 10-min ada 7 surau, 0 klinik 24j". Not generic.
